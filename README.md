# Real-Time ETL Research

Research artifacts for selecting an open-source real-time ETL platform for wallet event processing.

The main report is [reports/realtime-etl-research.md](reports/realtime-etl-research.md). Phase-2 Kubernetes proof artifacts are under `local-setup/phase2-k8s`, `local-setup/phase2-k8s-proofs`, and `screenshots/phase2-k8s`.

## Local Run Notes

Generated build output, downloaded/runtime state, database state, archives, and credential-like files are intentionally excluded from the public repository. Local execution still works because those files are regenerated by Maven, Docker, Docker Compose, or Kubernetes.

For the RocketMQ Streams phase-2 proof:

```bash
cd local-setup/rocketmq-streams-wallet-poc
mvn clean package
docker build -t etl-research/rocketmq-streams-wallet-poc:phase2 .
cd ../..
kubectl create namespace etl-research-phase2 --dry-run=client -o yaml | kubectl apply -f -
kubectl apply -f local-setup/phase2-k8s/rocketmq-streams.yaml
kubectl wait -n etl-research-phase2 --for=condition=complete job/phase2-rocketmq-streams-setup --timeout=8m
kubectl get pods -n etl-research-phase2
```

This proof consumes RocketMQ source events, filters authorized wallet payments with amount >= 100, enriches the JSON, and writes the transformed record to a RocketMQ sink topic.
